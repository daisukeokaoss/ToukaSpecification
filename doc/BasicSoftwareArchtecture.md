# Basic Software Architecture of Touka
Basic architecture of Touka is input random value to __A and __B for Intel intrinsic function and that of ported to OpenPOWER and RISC-V.  
And make sure if input value are same return value or raising exception are same.  
Strategy for passing value from or to Intel x86-64 and OpenPOWER or RISC-V is necessary.One option is by file transfer.
